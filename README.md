
Inventory Management System 📦  

A simple yet effective command-line-based Inventory Management System that helps users manage inventory seamlessly. This project provides functionalities to add, update, view, search, and save/load inventory data efficiently.  

 🔹 Features  
✅ Add Inventory – Add new items with details.  
✅ Update Inventory – Modify existing inventory entries.  
✅ View Inventory – Display all stored inventory items.  
✅ Search Inventory – Quickly find items by name or other attributes.    
✅ Error Handling – Ensures smooth operation by managing invalid inputs.  

🔹 Tech Stack  
- Python 🐍   
- Dictionaries & Functions (Data storage and processing)  

🔹 How It Works  
1️⃣ Run the program in a terminal.  
2️⃣ Choose an action (Add, Update, View, Search, Save/Load).  
3️⃣ Enter inventory details when prompted.  
4️⃣ Inventory details are stored in memory and displayed in the console.
